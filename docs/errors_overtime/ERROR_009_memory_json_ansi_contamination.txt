ROOT CAUSE
----------
Cascade from ERROR_006. When the local brain (Ollama subprocess) returns
responses with ANSI escape sequences embedded, those sequences flow through:

  ask_local_brain() -> local_brain.py
  -> ask_local() -> brain.py
  -> ask_brain() -> brain.py
  -> generate_memory_summary() -> Ag.py
  -> store_last_answer() or store_discussion() -> Ag.py
  -> memory[category][key] = contaminated_value
  -> save_memory() writes contaminated JSON to memory.json

The escape codes are stored literally in the JSON file and persist across
sessions. Every future session that loads memory.json reads corrupted data.

IMPACT
------
- Stored memory entries are truncated and garbled
- When those entries are shown via "show memory", the terminal output
  is corrupted
- When those entries are used as context passed to the brain, the brain
  receives garbage characters in its context
- The data cannot be used for meaningful recall
- Affects all entries stored while local brain mode was active

FIX APPROACH (do not implement until Phase 2)
---------------------------------------------
1. Fix local_brain.py to strip ANSI codes (see ERROR_006)
2. Clean existing memory.json entries:
   Apply a one-time ANSI strip pass over all string values in memory.json
   
   import re, json
   def strip_ansi(text):
       return re.sub(r'\x1B\[[0-9;]*[A-Za-z]', '', text)
   
   with open('memory.json') as f:
       memory = json.load(f)
   for category in memory:
       for key in memory[category]:
           if isinstance(memory[category][key], str):
               memory[category][key] = strip_ansi(memory[category][key])
   with open('memory.json', 'w') as f:
       json.dump(memory, f, indent=4)
